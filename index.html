Glam Estetica Intgral Gestor

Nuestro proyecto web es un sistema gestor de negocio para la estética “Glam” en Tandil. Por sistema gestor entendemos una aplicación donde el dueño de un negocio pueda administrar clientes, fechas, cuentas corrientes y realizar distintas funcionalidades que se adecúen a las necesidades particulares del usuario. En este caso, la funcionalidad específica para Glam es un generador de vouchers de regalo donde la dueña podrá elegir un cliente y un tratamiento y se podrá generar un voucher de regalo de ese tratamiento. Además, se contará con una funcionalidad de calendario donde se podrán acomodar los clientes (al estilo de una agenda) y la posibilidad de gestionar cuentas corrientes de los clientes. Hay cuatro entidades principales: el cliente, el voucher, el tratamiento y el calendario. El calendario tiene, además de los atributos de la fecha, clientes y tratamientos. El voucher tiene como atributos un cliente y un tratamiento. El cliente tiene como atributos un nombre, una deuda y un número de teléfono. El tratamiento tiene como atributos un nombre, una descripción corta y su costo. Voucher, cliente y tratamiento cuentan con un atributo identificador (ID) que funciona como clave primaria. Calendario hay una sola instancia de esta entidad que funciona como una suerte de gestor de objetos, no tiene copias.
